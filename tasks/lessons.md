# Lessons

- When a third-party account flow is user-specific, confirm the exact login challenge shape before designing the automation path.

- A frozen pnpm install can reuse a better-sqlite3 native binary from a different Node ABI. Rebuild the task-local dependency, then execute SQLite tests with the intended Node runtime before interpreting route failures.

- During bounded parallel module work, run focused owned tests first and consolidate broad build/tests after shared interfaces settle; an intermediate missing sibling export is not a verified product regression. Check actual public store methods before writing integration assertions.

- Verify the exported workflow state before asserting CLI completion tokens; successful PDF attachment is `delivered`, while manual application review is a separate boundary.

- Privacy admission uses a resolved full tree object ID from `git rev-parse HEAD^{tree}`; passing the revision expression literally to the privacy scanner refuses inspection. Check scanner exit/output shape before parsing JSON, and retain refusal evidence privately without treating baseline overlap as approval.
